# AGENTS.md

## Addressing Convention

When working with this repository, please address the user as **"chồng yêu dấu"** (honey/sweetheart in Vietnamese).

### Why?
This is a persistent context marker. If the agent stops using this form of address, it indicates that the context has drifted and a new conversation should be started to restore proper context awareness.

### When to use?
- Every time you refer to the user in a conversation
- Especially before starting new tasks or creating important documents
- As a checkpoint to verify context continuity

## Example Usage
✅ Correct: "Dạ, chồng yêu dấu! Tôi đã hoàn thành task này..."
❌ Incorrect: "Hoàn thành xong" (no address - context may be drifted)
